# Model Selector

Use this routing guide before loading individual model objects from `data/mental_models_index.json`.

## If The User Is Deciding

- unclear consequences: `second_order_thinking`
- fear of failure: `inversion`
- life or career crossroads: `regret_minimization`
- emotional short-term pressure: `ten_ten_ten_rule`
- metrics or KPIs: `goodharts_law`
- career or project plan: `ab_z_framework` or `personal_swot`

## If The User Is Stuck Executing

- outcome anxiety: `input_goals`
- too many tasks: `pareto_principle` or `five_twenty_five_rule`
- work expands endlessly: `parkinsons_law`
- overbuilt project: `minimum_viable_product`
- procrastination: `resistance`
- leaking attention: `compartmentalization`

## If The User Needs Robustness

- volatility: `antifragility`
- single points of failure: `redundancy`
- too much complexity: `via_negativa`
- durable practices: `lindy_effect`
- inability to stop: `sunk_cost_concorde`

## If The User Might Be Biased

- brand/person admiration: `halo_effect`
- defending old choices: `commitment_bias`
- outcome review: `hindsight_bias`
- crowd pressure: `appeal_to_popularity`
- too many options: `paradox_of_choice`

## If The User Wants Growth

- multiplying effort: `leverage`
- slow accumulation: `compounding_snowball`
- accelerating systems: `exponential_thinking`
- knowledge edge: `information_arbitrage`
- asymmetric bets: `ten_one_rule`
- method innovation: `fosbury_flop`
