# Hermes Project Context

This repository is a portable mental-model skill pack for agents.

## Load Order

1. Load `skills/mental-model-selector/SKILL.md` when the user asks for decision help, prioritization, risk review, productivity framing, or postmortems.
2. Read `data/mental_models_index.json` only after the skill is selected.
3. Select at most three models for a normal user request.
4. Produce a useful decision artifact, not a lecture.

## Boundaries

- Models are lenses, not laws.
- Ask clarifying questions only when needed.
- Do not overfit every situation to a named model.
