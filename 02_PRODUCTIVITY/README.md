# Productivity Models

Use these when the user is stuck, scattered, overbuilding, procrastinating, or confusing motion with progress.

Primary models:

- `input_goals`: convert outcome anxiety into controlled inputs.
- `pareto_principle`: identify the few tasks creating most value.
- `parkinsons_law`: apply timeboxes and constraints.
- `minimum_viable_product`: test the smallest real assumption.
- `five_twenty_five_rule`: protect the top priorities from attractive distractions.
- `compartmentalization`: stop one context from leaking into all others.
- `resistance`: convert avoidance into a tiny next action.

Agent rule: productivity advice must end with a visible next action and a review loop.
