# 10/1 Rule

Prefer bets where upside can be much larger than downside.

**Use when:** Choosing experiments, outreach, content, product bets, or learning paths.

## Diagnostic questions

- What is the downside if this fails?
- What is the plausible upside?
- Can I cap loss and preserve upside?
- How many attempts can I afford?

## Agent instruction

Run small downside-capped bets with explicit success and stop criteria.

## Failure mode

Calling a lottery ticket asymmetric when the odds are unknowable or the downside is hidden.
