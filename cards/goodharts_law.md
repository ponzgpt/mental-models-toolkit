# Goodharts Law

When a measure becomes the target, it stops being a reliable measure.

**Use when:** You are optimizing a metric, KPI, habit score, leaderboard, or proxy signal.

## Diagnostic questions

- What is the real goal behind this metric?
- How could someone game it?
- What behavior does this metric reward?
- What qualitative signal should stay visible?

## Agent instruction

Pair every target metric with a counter-metric and a human review rule.

## Failure mode

Treating dashboards as reality instead of instruments.
