# Fosbury Flop

A change in method can outperform more effort inside the old method.

**Use when:** You are competing in a mature workflow where everyone optimizes the same moves.

## Diagnostic questions

- What rule is assumed but not required?
- What constraint can be approached differently?
- What would look strange but legal?
- What evidence would prove the new method works?

## Agent instruction

Identify one convention and design a small test that violates it without violating the goal.

## Failure mode

Being contrarian for style instead of performance.
