# Minimum Viable Product

Build the smallest artifact that can test a real assumption with a real user.

**Use when:** A project is growing before its core assumption has been tested.

## Diagnostic questions

- What assumption must be true?
- What is the smallest test?
- Who can give useful feedback?
- What result would invalidate this?

## Agent instruction

Define one assumption, one artifact, one user, and one success threshold.

## Failure mode

Calling a low-quality version an MVP when it does not test the core risk.
