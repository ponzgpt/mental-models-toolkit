# A-B-Z Framework

Hold a current plan, a near alternative, and a fallback plan at the same time.

**Use when:** Planning a career move, project bet, business idea, or migration path.

## Diagnostic questions

- What is Plan A?
- What evidence would move me to Plan B?
- What is the survival fallback?
- What trigger forces a switch?

## Agent instruction

Define Plan A, Plan B, Plan Z, and the measurable trigger between them.

## Failure mode

Using Plan Z as an excuse to avoid committing to Plan A.
