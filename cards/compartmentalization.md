# Compartmentalization

Separate contexts so one domain does not leak into every other domain.

**Use when:** Work, study, health, relationships, and admin keep interrupting each other.

## Diagnostic questions

- Which context is leaking?
- What boundary is missing?
- What belongs in a capture note, not in my head?
- When will this context be reviewed?

## Agent instruction

Assign each concern to a specific note, folder, time block, or review loop.

## Failure mode

Suppressing important signals instead of giving them a proper container.
