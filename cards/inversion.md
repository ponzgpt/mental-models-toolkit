# Inversion

Solve backwards by asking what would guarantee failure, then avoid it.

**Use when:** The desired outcome is vague but the failure modes are easier to identify.

## Diagnostic questions

- What would make this fail predictably?
- What am I assuming must go right?
- Which mistake is irreversible?
- What should I stop doing first?

## Agent instruction

List the top failure paths and convert each into a prevention rule.

## Failure mode

Using inversion as pessimism instead of operational risk control.
