# Via Negativa

Improve a system by removing what harms it before adding more complexity.

**Use when:** More tools, habits, supplements, features, or plans are making things worse.

## Diagnostic questions

- What can I remove?
- What is creating drag?
- What would stop making the problem worse?
- Which addition is compensating for a bad default?

## Agent instruction

Delete or pause one harmful element before adding a new one.

## Failure mode

Using subtraction as avoidance when a positive action is required.
