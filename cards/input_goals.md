# Input Goals

Set goals around actions you control instead of outcomes you only influence.

**Use when:** Outcome goals create anxiety, procrastination, or false failure.

## Diagnostic questions

- What input can I do daily?
- What output should this input influence?
- How will I log completion?
- What is the minimum viable repetition?

## Agent instruction

Convert the outcome into a weekly input quota with a tracking note.

## Failure mode

Choosing inputs that are busywork rather than causal drivers.
