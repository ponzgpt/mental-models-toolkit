# Exponential Thinking

Some systems change by compounding rates, not linear increments.

**Use when:** Growth, learning curves, network effects, automation, or risk accelerates over time.

## Diagnostic questions

- What grows with each cycle?
- What rate matters?
- Where does the curve bend?
- What looks small now but scales fast?

## Agent instruction

Map the growth loop and identify the variable that changes the rate.

## Failure mode

Applying exponential assumptions to systems without a real feedback loop.
