# Decision Making Models

Use these when the user needs to choose, compare, stop, continue, or reason under uncertainty.

Primary models:

- `second_order_thinking`: inspect downstream consequences.
- `inversion`: identify avoidable failure paths.
- `regret_minimization`: choose with a long time horizon.
- `ten_ten_ten_rule`: separate short-term emotion from long-term consequence.
- `goodharts_law`: check whether a metric has become a bad target.
- `ab_z_framework`: define current plan, adjacent plan, and fallback.
- `personal_swot`: ground a strategy in strengths, weaknesses, opportunities, and threats.

Agent rule: never use more than three of these in one response unless the human asks for a full decision audit.
