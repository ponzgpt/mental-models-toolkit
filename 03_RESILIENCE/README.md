# Resilience Models

Use these when the user needs robustness, backup paths, fewer fragile dependencies, or a clean exit from a bad bet.

Primary models:

- `antifragility`: design for learning from small stressors.
- `redundancy`: protect against single points of failure.
- `via_negativa`: remove harmful complexity before adding more.
- `lindy_effect`: prefer durable primitives when novelty is costly.
- `sunk_cost_concorde`: evaluate future value instead of defending past cost.

Agent rule: resilience advice must distinguish capped downside from hidden downside.
