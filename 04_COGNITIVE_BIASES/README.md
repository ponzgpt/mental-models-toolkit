# Cognitive Bias Models

Use these when the user's reasoning may be distorted by identity, popularity, brand, hindsight, or too many options.

Primary models:

- `halo_effect`: separate one impressive trait from unrelated claims.
- `commitment_bias`: update after facts change without identity lock-in.
- `hindsight_bias`: review decisions based on what was knowable then.
- `appeal_to_popularity`: separate social proof from truth.
- `paradox_of_choice`: cap options to restore action.

Agent rule: bias checks should be surgical. Do not accuse the user of bias; test for it.
