# Growth And Leverage Models

Use these when the user wants scale, compounding, asymmetric upside, or a better method rather than more effort.

Primary models:

- `leverage`: turn repeated effort into reusable assets.
- `compounding_snowball`: build a loop that improves with repetition.
- `exponential_thinking`: reason about accelerating feedback loops.
- `information_arbitrage`: translate underused knowledge across contexts.
- `ten_one_rule`: prefer downside-capped bets with large upside.
- `fosbury_flop`: change method when the old method is saturated.

Agent rule: growth advice must identify the actual leverage point, not just say "scale it".
